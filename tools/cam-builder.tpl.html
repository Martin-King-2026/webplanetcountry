    3. Трансляции

    Первая — основная, остальные — резервные. Для YouTube вставьте ссылку на видео или на канал: тип определится сам. Типы: yt — видео YouTube, ytc — эфир канала YouTube, iframe — код встраивания другого сайта (адрес из src), hls — поток .m3u8, img — обновляемая картинка, link — просто ссылка.

    4. Что вставить в Blogger

    Новое сообщение → режим «HTML» → вставьте код. Справа: «Ярлыки» — метки, «Постоянная ссылка» → «Пользовательская ссылка» — адрес. Затем откройте пост «Все камеры» в режиме HTML и добавьте строку из последнего поля перед </ul>.
